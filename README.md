# fromOS — Starry v4

繁體中文創作靈感卡網站，共 44 張重新創作的提示。

## 本版更新
- 全站統一使用 Noto Sans TC（正黑體風格 Web Font），降低手機與桌機的字型差異。
- 卡片訊息區塊置中，但文句本身維持靠左對齊。
- 音樂開關改為喇叭圖示；靜音時顯示斜線。
- 背景音量較上一版提高 50%，並持續循環播放。
- 44 則提示改寫得更通用，可用於繪畫、文學、設計、音樂、攝影等創作。
- 移除「關於」。

## GitHub Pages
將 `index.html`、`style.css`、`app.js` 上傳至 repository 根目錄即可。

# fromOS v5

繁體中文創作靈感卡網站，共 66 則重新創作、可通用於各類創作形式的提示。

## 本版更新
- 66 張隨機創作提示卡。
- 卡片正反面改為純白色，移除封面曼陀羅、符號、裝飾線條與提示文字。
- 訊息文字區塊整體水平置中，但文字本身維持靠左；換行時第二行與第一行起點對齊。
- 音樂播放時顯示正常喇叭，靜音時才顯示斜線喇叭。
- 保留深藍星空背景與循環播放的空靈環境音。
- 全站使用 Noto Sans TC 網頁字型，提升手機與桌機顯示一致性。

來源參考自 **Oblique Strategies** by Brian Eno and artist Peter Schmidt.

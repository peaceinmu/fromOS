# fromOS

A static GitHub Pages site with 44 original Traditional Chinese creativity prompts inspired by oblique thinking.

## Interaction
- First view: card back only, no prompt shown.
- Click once: flip to a randomly selected prompt.
- Click again: flip back to the cover.
- Click again: flip to another random prompt.
- The same prompt will not appear twice in a row.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, `app.js`, and this README to the repository root, then enable Pages from the `main` branch and `/(root)`.
